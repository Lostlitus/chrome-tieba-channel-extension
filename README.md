# Chrome贴吧频道聊天插件

## 安装要求

- Chrome 116 或更新版本。
- 可以在自己的浏览器中登录贴吧网页版。

## 首次安装

1. 从 GitHub Release 下载 `tieba-channel-chat-0.1.0.zip` 。
2. 将 ZIP 解压到一个固定目录。解压后应能直接看到 `manifest.json`、`panel.html` 等文件。
3. 在 Chrome 地址栏输入 `chrome://extensions`，进入扩展管理页面。
4. 打开右上角的「开发者模式」。
5. 点击「加载已解压的扩展程序」，选择第 2 步中**直接包含 `manifest.json` 的目录**。如果解压软件多生成了一层文件夹，请进入该层后再选择。
6. 打开或刷新 <https://tieba.baidu.com/>，登录自己的贴吧账号。

ZIP 不能通过双击直接安装。安装后请保留解压目录，Chrome 会继续从该目录读取插件文件。

## 使用方法

1. 安装后刷新贴吧网页，点击贴吧页面右下角的「频道聊天」，或点击浏览器工具栏中的插件图标，打开侧边栏。可以在工具栏的拼图菜单中固定插件。
2. 输入贴吧名称并点击「查找」，然后在「吧频道」下拉框中选择频道。
3. 在输入框中输入消息，按 Enter 或点击「发送」；Shift + Enter 换行。
4. 点击输入框左侧的表情按钮，可搜索、选择表情，支持只发表情或与文字混排。
5. 点击消息旁的「↩ 回复」可引用该消息；点击引用栏的「×」取消回复。缺少回复标识的旧消息可能无法引用。
6. 向上查看历史消息后，可点击「回到最新消息」返回底部。

已有的图片、转发帖子和消息下方的贴表情可以查看。其中，文字表情支持发送；消息下方的「贴表情」暂不支持新增或取消。

## 更新已有安装

1. 关闭插件侧边栏。
2. 将新版本 ZIP 解压并覆盖原来的安装目录。
3. 在 `chrome://extensions` 找到「贴吧频道聊天室」，点击卡片上的重新加载按钮。
4. 刷新已经打开的贴吧网页，再重新打开侧边栏。

侧边栏中的「重新连接」用于重新连接账号与频道，不会加载磁盘上的新版本代码。通过 ZIP 安装的版本需要手动更新。

如果旧安装目录已被移动或删除，可在扩展管理页面移除旧安装，再按「首次安装」步骤加载新的解压目录。

## 常见问题

- **找不到页面上的入口**：先刷新贴吧网页；也可以从浏览器工具栏打开插件。
- **提示未登录或账号已变化**：在贴吧网页版确认登录状态，再点击侧边栏中的「重新连接」。每位使用者使用自己的登录账号。
- **查不到频道**：检查吧名是否正确，且该贴吧对当前账号有可访问的频道。
- **发送失败或消息未出现**：插件会显示提示。消息可能因网络、账号权限或贴吧风控而被拒绝；先确认是否已送达，再决定是否重试。插件不会自动重发。
- **部分图片无法预览**：仅指定图片来源支持自动预览；其他来源显示带域名的外部链接，可自行决定是否打开。
- **安装时提示无法加载清单**：确认选择的是直接包含 `manifest.json` 的解压目录，而不是 ZIP 文件或外层文件夹。
- **无法贴表情**：Chrome插件不支持原生TCP长连接，贴表情依赖该模式发送请求。

## 隐私与卸载

插件使用当前浏览器的贴吧登录状态，消息直接提交给百度服务，不依赖开发者的消息中转服务器。频道成员可按贴吧的规则查看已发送消息。完整说明可从侧边栏底部的「隐私说明」打开。

需要卸载时，在 `chrome://extensions` 找到本插件并点击「移除」，之后可以删除解压目录。卸载插件不会撤回已发送到贴吧的消息。

本插件是非官方客户端，与百度及百度贴吧无隶属或背书关系。由于百度贴吧服务端部分请求缺少鉴权，因此本项目不发布源码，避免恶意二次开发。
